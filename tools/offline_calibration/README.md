# C离线标定工具 · ABC v1.4适配版

双击index.html，用Edge或Chrome打开。点击“载入当前版本 800×480 配置”，添加原始RGB图和目标掩膜，生成ROI、运动线、阈值与极性、遮挡保护及空场参数。

检查通过后点击“导出控制台算法场景”，在主控制台“FPGA算法 / 三路并行”页载入。导入后保持暂停，清空检测区后点击“自动判遮挡”开始计数。

当前工程使用800×480算法图像、从右向左运动和75 MHz计时。动态降噪、三阈值并行、峰谷切分、轨迹恢复与测速继续使用板上配置。

- index.html：工具入口。
- 使用说明.md、help.html：采图、标注、标定及应用步骤。
- reference/ABC_v1.4_800x480_base.json：当前版本基础配置。
- abc_adapter.js：当前控制台场景导出。
- examples/合成演示：96×64流程示例。
- tests：模型、页面、PNG与B像素规则对照。

本次模型与页面检查50项、PNG与B参考对照254项通过；当前控制台字段及参数提交检查见完整交付包verification/calibration目录。
