# 离线标定工具使用说明

适用ABC v1.4系列，算法与LCD坐标均为800×480，传送带方向为从右向左，算法时钟75 MHz。

## 从采图到应用

1. 保持机位、对焦和照明固定，在控制台点击“取高清图调框（暂停）”。每次采图生成的800×480 RGB图位于console/snapshots下的algorithm_800x480.png。
2. 采集至少2张不同空带训练图、2张不同物体训练图；另取至少1张空带和1张物体作为独立验证图。物体样本覆盖右、中、左位置。另采集暗色和暖色遮挡验证图各1张。
3. 为物体图制作同尺寸黑白掩膜：目标全部涂白，背景涂黑。图像和掩膜使用不透明PNG，掩膜采用纯黑与纯白。
4. 双击index.html，用Edge或Chrome打开，点击“载入当前版本 800×480 配置”。也可以导入reference/ABC_v1.4_800x480_base.json。
5. 按用途逐张添加RGB图与物体掩膜，点击“生成离线候选”。页面显示ROI、运动两线、保护区、阈值带和样本检查结果。
6. 检查通过后，点击“导出控制台算法场景”，得到ABC_v14_标定算法场景.json。
7. 在控制台“FPGA算法 / 三路并行”页点击“载入算法场景”，选择导出的JSON。控制台提交参数、读回生效结果，并保持暂停。
8. 清空检测区，点击“自动判遮挡”，等待状态恢复正常后启动传送带。需要人工控制遮挡状态时，使用“正常计数·手动无遮挡”。

## 标定内容

- ROI：根据训练掩膜联合包围范围向外扩展8像素，图像边缘保留2像素。
- 运动线：在ROI中安排右侧入口线A、左侧出口线B，满足基础配置中的滞回间距。
- 二值化：使用FPGA的整数灰度公式(77R+150G+29B+128)>>8，搜索阈值与前景极性。
- 保护区：在训练目标ROI之外搜索亮度稳定的矩形区域，计算暗色与暖色进入/退出门限。
- 空场：根据训练背景占用率生成以1/256为单位的空场比例。
- 独立检查：复核留出空带、留出物体和两类遮挡图；页面列出待补样本或具体失败原因。

## 与当前算法配合

导出的算法场景使用ABC-1.4格式。ROI和保护区采用左上包含、右下不包含的像素坐标，直接对应LCD画面。

导出同时设置初始阈值、训练得到的连续阈值带上下限，以及按训练空带均值计算的动态阈值偏移。动态阈值开关沿用板上配置；开启时，FPGA在标定阈值带内继续调整。

动态降噪、三阈值并行、峰谷切分、合并恢复、测速、多帧稳定的开关与算法参数沿用板上配置。这些功能在控制台算法页调整。场景导入切换到相机源、采用软件配置并保持人工暂停，清空检测区后选择运行模式。

保护区、空场确认帧数、轨迹关联参数与75 MHz超时值一起导出。控制台按现有协议分配配置版本和场景版本。

## 页面与记录

“导出完整检查记录JSON”保存候选、阈值带、逐帧统计和样本摘要；“导出控制台算法场景”保存可直接载入控制台的参数。96×64合成演示用于展示流程；800×480样本生成当前控制台的场景文件。

候选中的calibrated字段记录离线候选阶段；ABC算法场景包含已通过样本检查的参数和载入后的暂停状态。

每次最多20张RGB图，单张PNG不超过20MB。目标贴边、尺寸不足、阈值分离失败或遮挡检查失败时，按页面提示调整采样或标注。机位、光照或物品范围改变后，建立新样本组重新标定。

## 开发与复现

浏览器入口直接读取本地HTML与JavaScript，日常使用双击index.html即可。PNG命令行桥接使用Python、Pillow和Node：

```powershell
python run_model.py examples/合成演示/manifest.json --node node --output 我的标定报告.json
node --test tests/model.test.js tests/app.test.js tests/abc_adapter.test.js
```

reference/b_scene_reference.py提供B像素规则对照；abc_adapter.js负责800×480基础配置与控制台场景导出。
