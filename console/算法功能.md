# B算法整机接入与操作

B的完整流水线已接入相机、PS控制、RGBLCD和BRAM自测。控制台“FPGA算法 / 三路并行”页配置并读回全部算法参数。

| 功能 | 配置入口 | 结果 |
|---|---|---|
| 动态阈值 | cfg_auto_threshold、threshold_min/max、mean_offset、threshold_step | active_threshold、mean_gray |
| 动态降噪 | cfg_auto_denoise、noise_on/off、noise_confirm | active_mode、noise_stats_* |
| 形态学 | cfg_mode：0旁路、1腐蚀、2膨胀、3开运算 | out_mode、out_binary |
| 三阈值并行与融合 | cfg_parallel_enable、threshold_delta、interval_tolerance | low/center/high计数、parallel_support、motion_objects_* |
| 峰谷切分 | cfg_valley_enable、valley_ratio/depth/width、peak_distance/support | result_cut_count、cut_x及LCD绿色切割线 |
| 动态轨迹计数 | cfg_motion_enable、line_a/b、hysteresis、min_hits、max_step | camera_total、test_total、motion_event_* |
| 合并与恢复 | cfg_merge_enable、merge_max_frames/confirm_frames、形状与恢复容差 | merge_active/recovering、restored_groups |
| 相关测速 | cfg_speed_enable、speed_min_foreground、speed_margin | speed_dx、cycles_per_frame、像素/秒 |
| 多帧稳定 | cfg_stable_mode：0原始、1五帧中值、2连续N帧 | stable_count、stable_current_confirmed |
| 场景保护与恢复 | safety_roi_*、guard_*、recovery_normal/empty_frames | safety_state、reason、恢复进度 |
| 静态ROM/动态BIST | cfg_test_async、scene、bist_dynamic/profile/seed | 独立累计、expected/actual_count、BIST PASS |

自动去噪按孤立噪声比例、迟滞门限与连续帧确认切换旁路/开运算。关闭自动去噪后，可用cfg_mode选择固定模式。三路并行关闭时，动态计数采用中心路目标区间。静态多帧稳定和动态轨迹容错分别作用于静态结果与通过事件。

ROI使用800×480显示坐标，边界为左闭右开。入口线A位于右侧，出口线B位于左侧。小目标可降低cfg_high、cfg_min_width等投影门限，并按目标实际位移设置max_step。

相机累计与测试累计独立，切换输入源保留累计。人工暂停保持视频并冻结自适应反馈，解除后经过正常帧和空场确认恢复。算法事件按序号、轨迹ID、帧号、来源、会话和上下文记录到logs/*.events.jsonl。

sys_dip_override选择拨码参数字优先；sys_dip_bits的位0选择自测、位1选择动态自测、位3:2选择场景，位4～7依次控制动态阈值、动态降噪、并行融合和峰谷切分。控制台和串口VDIP命令均可设置该参数字。

静态ROM与动态BIST按钮自动完成源切换，重复点击动态BIST会重新启动完整测试。

自测场景使用亮目标，切入自测后自动选择亮目标极性、均值偏移+24；返回相机后恢复已保存的极性及偏移。配置读回保留相机设置，结果中显示正在使用的阈值与去噪模式。

参数整包在帧间边界提交，配置版本及场景版本同步更新。完整索引、位宽和结果映射见vision_registers.json。GPIO控制地址为0x43C40000，PS邮箱协议为4，算法标识为C31401。

LCD显示十进制累计、静态计数、三路阈值、稳定结果、位移及帧间周期；后六项数值采用十六进制，控制台显示十进制。下方红线为投影波形，绿色线为峰谷切割位置。
