# 控制台 v1.2

升级时先停带，关闭旧控制台，打开本目录“控制台.exe”，选择开发板串口并点击“初始化开发板”。初始化下载新版 ARM 固件并清零，完成后保持手动暂停；不能只点“连接设备”。旧版板上协议会被明确拒绝。

修正内容：
- 恢复主循环 cup_poll()，保留 UART 手输命令与收发日志。
- 常用按钮通过已有 JTAG/DDR 邮箱提交模式、ROI、阈值、显示和清零，核对板卡应答、实际配置及版本；手动模式还核对有效遮挡位。
- 板上邮箱协议升级为 3，拒绝仅换电脑界面、板上仍运行旧固件的情况。
- 程序、窗口标题和页面名称均为“控制台”，右上角显示 v1.2。

手动有遮挡只暂停计数，保留累计，视频继续。手动无遮挡覆盖自动像素否决；清空两框后才恢复计数。自动模式仍可能受背景亮度影响，本版本不声称解决旧图像规则的误判或相互遮挡杯子的分离。

本地编译、实际 C 邮箱/命令分派/配置程序联合检查（PL 使用模拟）、控制器与界面检查通过。真实开发板加载与经过计数验收待完成，参见 validation。
