# 控制台：串口与调框合一

本包为 v1.4，恢复串口命令处理并使用带版本校验的板卡控制邮箱。升级时点击“初始化开发板”，下载配套固件并清零；详见《修复说明.md》。

## 开始使用

1. 摄像头保持直插，LCD、电源、USB串口和JTAG连接保持原样。先停传送带，在SSCOM点击“关闭串口”，避免两个程序占用同一COM口。
2. 双击本文件夹的 **控制台.exe**。选择实际的开发板串口（本机为COM3），通信参数固定为115200、8N1。
3. 首次使用、当前运行旧程序或开发板重启后，点击 **初始化开发板**。这个操作会下载配套程序并清零，窗口会先说明。完成后默认“手动暂停”。以后配套程序仍在运行时，点击 **连接设备**即可，不必重新初始化。
4. 点击 **取高清图调框（暂停）**，等待画面出现。拖动黄色A和青色B框，或输入右侧数字；点击 **应用检测框（保持暂停）**。
5. 清空检测区，确认相机和传送带固定，点击 **正常计数·手动无遮挡**，再启动传送带。

常用按钮经已连接的JTAG/DDR邮箱提交并读回，串口页仍可手输命令和查看收发日志。日常操作通过窗口按钮完成。窗口关闭后板卡保持原来的模式；要停计数，请先点击暂停。

## 常用按钮

| 按钮 | 实际作用 |
|---|---|
| 正常计数·手动无遮挡 | 切换为人工确认无遮挡，等待检测区清空后计数，累计数保留 |
| 暂停计数·有遮挡 | 人工暂停，保留累计数；手进入检测区前先点此按钮 |
| 自动判遮挡 | 使用B场景监督，按正常帧与空场确认自动恢复 |
| 计数清零 | 明确清零，检测框与模式不变；操作前会说明 |
| 取高清图调框 | 暂停计数，导出一张彩色原图并冻结，随后恢复视频，计数保持暂停 |
| 应用检测框 | 先暂停，发送五个框参数并核对板上生效版本及配置，累计数保留 |
| 恢复实时预览 | 退出高清冻结图，继续显示新相机灰度预览，计数模式保持当前设置 |
| 保存已生效场景 | 保存实际生效的定位、阈值和显示配置 |
| 载入场景 | 恢复本程序保存的配置，完成后保持暂停，点击正常计数后开始运行 |

框的位置以LCD的800×480为准，A在右、B在左，用于从右到左经过的杯子。宽度1～32，高度至少8，上边界至少2；越界时显示红色提示，修正后提交。

实时预览是相机输入的160×90灰度取样，在窗口中放大显示。精细调4像素窄框时建议取高清图。高清图是1280×720原始彩色图的中央800×480裁剪，保留原始裁剪像素，标为冻结；实时画面超过3秒没有新身份或断线时会提示过期。

## 串口日志与高级设置

切换到 **串口日志 / 高级** 页，可查看接收/发送内容、修改阈值、显示识别掩膜、输入英文命令和保存日志。发送使用文本模式并自动附带换行。清空显示后，原日志保存在logs。

阈值范围32～224，应用阈值也会先暂停。配置提交后读回生效版本与参数。

原始接收字节和带时间的操作日志自动保存在logs；高清照片和元数据保存在snapshots。高清图附带采集编号和哈希，日志记录状态版本及算法上下文。

## 算法功能

本版接入B完整算法。FPGA轨迹处理支持右到左计数、抖动容错、合并保持与重新分离恢复；相机缩略图用于定位预览。

实际计数采用B v0.13完整流水线，算法页可配置动态阈值、动态降噪、形态学、三阈值并行融合、峰谷切分、合并恢复、测速、多帧稳定、场景保护及BRAM自测，并读回当前结果。详细参数见算法功能.md。

控制台依赖AMD 2025.2、Python、Pillow、NumPy、Tk和Windows .NET。保留完整目录；XSDB_EXE与FPGA_PYTHON可指定本机工具路径。 控制台自动查找Vivado或Vitis中的XSDB；本机使用E:/JLU/AMD_Vivado/2025.2/Vivado/bin/xsdb.bat。

## 检查与运行

整链自检覆盖裁剪、背压、动态降噪、三路并行、峰谷切分、轨迹事件、合并恢复、相关测速、四种动态BIST、GPIO与显示快照。配置解码、完整位宽计数及Tk算法页面检查通过。检查结果见../verification/。

运行顺序：初始化保持暂停 → 取图定位 → 设置ROI和算法参数 → 应用并读回 → 正常计数 → 暂停/恢复 → 保存场景。可在算法页切换静态ROM或动态BIST，显示期望/实际计数与PASS结果。

## 离线标定

使用../tools/offline_calibration/index.html生成当前800×480场景。在“FPGA算法 / 三路并行”页点击“载入算法场景”，选择标定工具导出的ABC_v14_标定算法场景.json。导入后保持暂停；清空检测区后点击“自动判遮挡”。高清原图从console/snapshots中的algorithm_800x480.png选取。
