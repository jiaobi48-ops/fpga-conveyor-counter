# 控制台：串口与调框合一

本包为 v1.2，恢复串口命令处理并使用带版本校验的板卡控制邮箱。升级后必须点击一次“初始化开发板”，将下载新固件并清零；详见《修复说明.md》。

## 开始使用

1. 摄像头保持直插，LCD、电源、USB串口和JTAG连接保持原样。先停传送带，在SSCOM点击“关闭串口”，避免两个程序占用同一COM口。
2. 双击本文件夹的 **控制台.exe**。选择开发板串口（此前为COM8），不需要输入波特率；固定115200、8N1。
3. 首次使用、当前运行旧程序或开发板重启后，点击 **初始化开发板**。这个操作会下载配套程序并清零，窗口会先说明。完成后默认“手动暂停”。以后配套程序仍在运行时，点击 **连接设备**即可，不必重新初始化。
4. 点击 **取高清图调框（暂停）**，等待画面出现。拖动黄色A和青色B框，或输入右侧数字；点击 **应用检测框（保持暂停）**。
5. 清空检测区，确认相机和传送带固定，点击 **正常计数·手动无遮挡**，再启动传送带。

常用按钮经已连接的JTAG/DDR邮箱提交并读回，串口页仍可手输命令和查看收发日志。日常无需手输ROI、U、H等命令，也无需打开Vivado。窗口关闭后板卡保持原来的模式；要停计数，请先点击暂停。

## 常用按钮

| 按钮 | 实际作用 |
|---|---|
| 正常计数·手动无遮挡 | 切换为人工确认无遮挡，等待检测区清空后计数；不会清零 |
| 暂停计数·有遮挡 | 人工暂停，保留累计数；手进入检测区前先点此按钮 |
| 自动判遮挡 | 使用现有暖色/上方背景规则；不是自动跟随，某些背景会误触发 |
| 计数清零 | 明确清零，检测框与模式不变；操作前会说明 |
| 取高清图调框 | 暂停计数，导出一张真实彩色原图并冻结，随后恢复视频；不会自动恢复计数 |
| 应用检测框 | 先暂停，发送五个框参数并核对板上生效版本及配置；不清零 |
| 恢复实时预览 | 退出高清冻结图，继续显示新相机灰度预览；不改变计数模式 |
| 保存已生效场景 | 保存板上实际框、阈值及掩膜显示选项，不把未提交草稿冒充生效配置 |
| 载入场景 | 恢复本程序保存的配置，完成后保持暂停，不自动开始计数 |

框的位置以LCD的800×480为准，A在右、B在左，用于从右到左经过的杯子。宽度1～32，高度8～128，上边界至少54；越界时显示红色提示，不下发。

实时预览是相机输入的160×90灰度取样，在窗口中放大；不是完整彩色视频流。精细调4像素窄框时建议取高清图。高清图是1280×720原始彩色图的中央800×480裁剪，无缩放、无COUNT或框线污染，明确标为冻结；实时画面超过3秒没有新身份或断线时会提示过期。不能把旧画面当作当前画面。

## 串口日志与高级设置

切换到 **串口日志 / 高级** 页，可查看接收/发送内容、修改阈值、显示识别掩膜、输入英文命令和保存日志。发送自动附带换行，不需要勾选HEX或定时发送。清空显示只清窗口，原日志仍在logs。

阈值范围32～224，应用阈值也会先暂停。设置完成后按钮结果以板上读回为准，操作中的提示不会提前当作成功。未收到确认时显示错误，不自动重复发送，避免意外清零或重复提交。

原始接收字节和带时间的操作日志自动保存在logs；高清照片和元数据保存在snapshots。状态与灰度预览来自最近各自的快照，不承诺同一曝光帧；采集编号不是摄像头曝光ID。

## 当前版本范围

本次用户要求取消自动跟随：电脑端不提供TRACK/FOLLOW，配套ARM程序不编译匹配器或跟随服务。原bit中的观察器仅用于读相机缩略图，初始化明确关闭跟随使能，预览服务没有发计数许可的操作。原自动跟随工程与先前9张照片交付包都保留原样。

实际计数仍是当前A的两检测带算法和手动遮挡控制。B/C新材料是界面与对比实验建议，没有新的板上接口；本程序未接入B v0.13，不提供尚未接入的动态阈值、形态学、三阈值融合等虚假开关，不生成标定完成或准确率数据。

本机依赖现有AMD 2025.2、Codex捆绑Python/Pillow/NumPy及Windows .NET。EXE是无控制台启动入口，必须与本文件夹内其他文件一起保留，不是可单独拷走的免依赖程序。迁移电脑需修改运行环境路径。

## 验证状态

已完成配套ARM编译与链接、实际C串口解析测试、预览服务测试、模拟UART/JTAG控制与生效版本检查、实际Tk控件/拖框/过期状态测试、Tcl下载入口模拟测试，以及中文窗口显示检查。

用户选择稍后联调，本轮未将新固件下载到开发板，没有签核新程序的实物计数、真实串口按钮控制或高清取图效果。之前固定框计数“正常”的反馈属于此前程序，不能直接作为本程序验收。实景闪点也未修复。

首次联调顺序：初始化保持暂停 → 取图调框 → 应用 → 正常计数 → 单只杯子四次通过 → 暂停/恢复 → 保存/载入场景。杯子互相遮挡、粘连时，两检测带可能无法分开累计，不能据按钮齐全宣称这类工况已解决。
